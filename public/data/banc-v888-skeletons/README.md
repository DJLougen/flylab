# BANC v888 morphology render assets

These six binary line assets are display derivatives of the BANC v888 L2 SWC skeleton products for the four pinned MDNs and two pinned LBL40 cells used by FlyLab.

- Source: BANC materialization v888, snapshot 2026-04-17
- Dataset: [Harvard Dataverse 10.7910/DVN/7WTH1N](https://doi.org/10.7910/DVN/7WTH1N)
- Article: [Bates et al., *Nature* (2026)](https://doi.org/10.1038/s41586-026-10735-w)
- Source documentation: [BANC released data products](https://github.com/htem/bancpipeline#released-data-products)
- Source license: CC BY 4.0

`manifest.json` records each raw SWC URL and SHA-256 checksum, the shared coordinate transform, source and render counts, and the simplification boundary. The transformation preserves roots, branch points, endpoints, and intermediate nodes selected by cumulative path distance. The surrounding CNS shell in FlyLab is schematic and is not part of these assets.
